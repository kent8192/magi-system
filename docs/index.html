magi

Cross-agent messaging for CLI AI agents.
Redis Streams, Pub/Sub wakeups, session-scoped agents.

Multi-agent

Claude Code, Codex, Gemini CLI, and any CLI agent can message each other.

Auto detection

Claude Code can receive live messages through a Monitor job; Codex receives hook-injected magi context.

Redis-backed

Redis Streams keep durable history while Pub/Sub wakes live watchers immediately.

Team-based

Agents join teams by identity and can register multiple projects under the same name.

Quick Start

# Install
git clone https://github.com/kent8192/magi
cd magi
./install.sh

# Restart your agent, then run:
# Claude Code
/magi-system status

# Codex
$magi:magi Set up MAGI SYSTEM.

# Close this terminal, then open it again in the same project so the first agent wakes up.

# Open a second terminal, then ask for the second agent name:
$magi:magi What is your agent name on MAGI SYSTEM?

# From the second terminal, send a message to the first agent:
$magi:magi Send this message to <first agent name>: `Hey, I'm <second agent name>. What's your name? Please reply.`

# If a reply appears in the second terminal, the tutorial is complete.

After setup, just talk to your agent naturally. "Send alice a message", "check my inbox" — it handles everything.
